# 🚀 Zamonaviy Shaxsiy Portfolio (React + Tailwind CSS + JavaScript)

React, Tailwind CSS va zamonaviy JavaScript (ES6+) yordamida yaratilgan chiroyli, interaktiv va to'liq responsive shaxsiy portfolio veb-sayti.

---

## ✨ Loyihaning Asosiy Xususiyatlari

- ⚡ **Tezkor va Yengil**: Vite vositasi yordamida tezkor ishlash va qaynoq yangilanish (HMR).
- 🎨 **Zamonaviy Dizayn**: Tailwind CSS, Dark glassmorphism, chiroyli gradientlar, hover effektlar va mikrografikalar.
- 📱 **100% Moslashuvchan (Responsive)**: Smartfonlar, planshetlar va katta ekranlar uchun to'liq moslangan mobil menyu.
- 🧩 **Modulli Komponentlar**:
  - **Navbar**: Silliq scroll, mobil menyu (burger menyu), doimiy fixed qatlam.
  - **Hero**: Yashil faollik indikatori, ta'sirchan sarlavha, interaktiv kod vizualizatsiyasi va ijtimoiy tarmoqlar.
  - **About**: Qisqacha bio, asosiy ustunliklar va ta'sirchan statistika kartalari.
  - **Skills**: Texnologiyalar darajasini ko'rsatuvchi vizual progress barlar va texnologiya nishonlari.
  - **Projects**: Kategoriyalar bo'yicha filtrlash (Web App, E-Commerce, Dashboard, Landing), batafsil ko'rish uchun modal oyna, jonli demo va GitHub havolalari.
  - **Services**: Taklif etilayotgan xizmatlar ko'rgazmasi.
  - **Experience**: Timeline (vaqt chizig'i) ko'rinishidagi ish va ta'lim tajribasi.
  - **Contact**: Interaktiv xabar qoldirish formasi (yuborish tasdig'i bilan) va tezkor aloqa havolalari.
  - **Footer**: Mualliflik huquqi, ijtimoiy tarmoqlar va yuqoriga qaytish (Scroll to Top) tugmasi.

---

## 🛠 O'rnatilgan Texnologiyalar

- **React 18** (Komponentlar, Hooks, Holat boshqaruvi)
- **Tailwind CSS 3** (Zamonaviy styling va qulayliklar)
- **Vite** (Next Generation Frontend Tooling)
- **Lucide React & Custom SVG** (Chiroyli piktogrammalar)

---

## ⚙️ Loyihani Ishga Tushirish

Loyihani kompyuteringizda ishga tushirish uchun quyidagi buyruqlarni terminalda bajaring:

### 1. Bog'liqliklarni o'rnatish:
```bash
npm install
```

### 2. Dasturchi rejimida ishga tushirish (Dev Server):
```bash
npm run dev
```
Brauzerda `http://localhost:5173` manzilini oching.

### 3. Loyihani ishlab chiqarishga (Production) yig'ish:
```bash
npm run build
```
